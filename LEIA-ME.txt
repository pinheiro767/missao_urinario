COMO JOGAR LOCALMENTE
1. Extraia/descompacte TODO O ZIP (não abra o index.html dentro do ZIP).
2. Abra index.html no navegador. Mantenha app.js, style.css e a pasta imagens juntos.
3. Use os botões de toque no celular ou setas e espaço no teclado.

ALTERNATIVA SEM PASTAS
Use Missao_Urinaria_Jogar_Sem_Pastas_CORRIGIDO.html. Todos os recursos ficam dentro de um arquivo HTML; ótimo para testar em um navegador que abre arquivos HTML locais. Essa versão NÃO instala como PWA.

COMO INSTALAR COMO APLICATIVO
Suba os arquivos soltos e a pasta imagens para a raiz de um repositório GitHub Pages.
Abra a página HTTPS no Safari ou Chrome; escolha "Adicionar à Tela de Início" / "Instalar app".
Quando carregado e cacheado uma vez, o jogo também funciona offline.

INCLUÍDOS: 4 fases; 13 desafios; caminhada, salto e coleta; som gerado no navegador; confetes, medalhas; relatório CSV; impressão de certificado em PDF.

SOM: navegadores exigem um primeiro toque no botão Iniciar para liberar áudio.
Se seu aparelho bloquear arquivos HTML locais, publique no GitHub Pages ou teste em Chrome/Firefox.
